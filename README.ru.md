# MIT/Runo

**Терминальный текстовый редактор на Rust с привычным управлением GNU nano.**

[English](README.md) · [Совместимость](docs/compatibility.md) ·
[Участие в разработке](CONTRIBUTING.md) · [История версий](CHANGELOG.md)

MIT/Runo стремится воспроизвести опыт редактирования **GNU nano 8.2** в
Rust-реализации под MIT. Откройте файл, введите текст, сохраните его через
`Ctrl+S` и выйдите через `Ctrl+X`. Установленный nano для работы не нужен.

**Статус: ранний выпуск, 0.1.0.** Полная совместимость с nano 8.2 пока не
достигнута. В заголовке терминала отображается `MIT/Runo 0.1`.
Поддерживаемая платформа — **Linux с glibc**; CI и проверка лицензий
ориентированы на `x86_64-unknown-linux-gnu`.

## Возможности

- Несколько буферов, выделение, cut/copy/paste, отмена и повтор правок.
- Поиск в обоих направлениях и интерактивная замена, POSIX ERE и группы
  `\1`–`\9` в строке замены.
- UTF-8, широкие символы, комбинирующие знаки, форматы строк Unix/DOS/Mac.
- Номера строк, мягкий перенос, отступы, выравнивание и дополнение слов.
- Подсветка из поддерживаемого подмножества `.nanorc`, переназначение клавиш,
  клавиатурные макросы.
- Файловый браузер, резервные копии, advisory lock-файлы и обнаружение
  внешних изменений перед сохранением.
- Вставка вывода команд, передача буфера в pipe, внешние speller/formatter/linter.
- Мышь, bracketed paste, запоминание позиции и аварийное сохранение
  при SIGHUP/SIGTERM.

## Сборка и установка

Нужны **Rust 1.82+**, Cargo, C-линкер и инструменты сборки, Linux с glibc и
UTF-8-терминал. В Debian/Ubuntu нативные инструменты доступны в пакете
`build-essential`. Если версия системного Rust ниже 1.82, установите актуальный
через [rustup](https://rustup.rs/).

Из каталога скачанного или клонированного проекта:

```sh
cargo build --release --locked
./target/release/runo notes.txt
```

Установка команды в каталог бинарников Cargo (обычно `~/.cargo/bin`,
который должен быть в `PATH`):

```sh
cargo install --path . --locked
runo --version
```

## Запуск

```sh
runo                         # Пустой буфер
runo notes.txt               # Открыть или создать файл
runo +12,8 notes.txt          # Строка 12, столбец 8
runo -lS first.txt second.txt # Номера строк, мягкий перенос, два буфера
printf 'hello\n' | runo -     # Прочитать stdin и перейти к терминалу
runo -I notes.txt            # Запуск без настроек
runo --help                  # Параметры командной строки
```

### Основные клавиши

`^` в подсказках означает Ctrl, `M-` — Alt. Вместо Alt можно нажать Escape,
затем нужную клавишу.

| Действие | Клавиши |
| --- | --- |
| Справка | `Ctrl+G` |
| Сохранить | `Ctrl+S` |
| Записать под выбранным именем | `Ctrl+O` |
| Закрыть буфер / выйти | `Ctrl+X` |
| Поиск вперёд / назад | `Ctrl+W` / `Ctrl+Q` |
| Замена | `Alt+R` |
| Перейти к строке и столбцу | `Alt+G` |
| Начать / снять выделение | `Alt+A` |
| Вырезать / копировать / вставить | `Ctrl+K` / `Alt+6` / `Ctrl+U` |
| Отмена / повтор | `Alt+U` / `Alt+E` |
| Предыдущий / следующий буфер | `Alt+<` / `Alt+>` |
| Прочитать файл | `Ctrl+R` |
| Выполнить команду | `Ctrl+T` |

Shift+стрелки тоже выделяют текст. Полная справка доступна через `Ctrl+G`.

## Настройки

Порядок загрузки, от меньшего приоритета к большему:

1. `/etc/nanorc`.
2. Первый существующий файл: `~/.nanorc` или `$XDG_CONFIG_HOME/nano/nanorc`.
3. Первый существующий файл: `~/.runorc` или `$XDG_CONFIG_HOME/runo/runorc`.
4. Параметры командной строки.

По умолчанию `XDG_CONFIG_HOME` — `~/.config`. `-I` отключает загрузку настроек,
`-f FILE` читает только указанный файл.

Пример `~/.runorc`:

```text
set linenumbers
set softwrap
set autoindent
set tabsize 4
set tabstospaces
```

В [examples/runorc](examples/runorc) есть дополнительные настройки и
необязательное подключение системных определений подсветки nano. Эти
определения в поставку не входят. Для `--magic` нужна утилита `file`, для
орфографии, форматирования и линтинга — соответствующие внешние программы.

`set historylog` и `set positionlog` включают сохранение состояния в
`$XDG_STATE_HOME/runo/` или `~/.local/state/runo/`, отдельно от nano.
В restricted-режиме эти файлы не читаются и не записываются.

## Ограничения

Поддерживается только корректный UTF-8; интерфейс пока англоязычный.
Поддержка nanorc, обработка конфликтов lock-файлов, дополнение и некоторые
детали редактирования отличаются от nano. macOS, Windows и Linux с musl
пока не поддерживаются и не тестируются. Подробнее — в
[заметках о совместимости](docs/compatibility.md).

## Разработка

Для Python-проверок достаточно Python 3 со стандартной библиотекой:

```sh
cargo fetch --locked
python3 scripts/audit_licenses.py
cargo fmt --check
cargo clippy --locked --all-targets -- -D warnings
cargo test --locked
cargo build --release --locked
python3 tests/pty_smoke.py target/release/runo
```

В наборе 17 Rust-тестов, включая 1 800 случайных операций редактирования,
и 25 сценариев через настоящий псевдотерминал. GitHub Actions запускает
проверки на stable Rust и тестирует минимальную поддерживаемую версию.
См. [CONTRIBUTING.md](CONTRIBUTING.md) и
[подготовку релиза](docs/releasing.md).

Разработка Runo велась в рамках AI-ориентированного clean-room процесса: код 
создавался по спецификациям поведения GNU nano 8.2 и проходил жёсткую верификацию 
через автоматические PTY-сценарии, рандомизированные тесты и строгий линтинг Clippy.
